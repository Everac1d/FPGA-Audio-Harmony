# 高云FPGA实时变调与和声系统

FPGA 实时变调、双声部和声与五分钟录放系统。

本工程包含完整源码、IP、约束、仿真输入与正式烧录文件。

器件 **GW5AST-138B / GW5AST-LV138PG484AC1/I0**，顶层 `audio_record_ddr_top`。完整解压到独立目录后打开 [audio_lcd_record_b.gprj](audio_lcd_record_b.gprj)。直接下载 [烧录位流](ready_to_program/高云FPGA实时变调与和声系统_正式烧录位流.fs)，核对UserCode **0x00033109**。启动默认实时静音、原声、增益1.0倍、普通变调0、和声两声部0／0。

音效循环只有原声、变调、和声三项。和声为两个独立声部，默认均为+00；任一声部为0半音时使用对齐原声，0/其他半音即原声加变调。普通变调参数独立保存、默认0。全部半音范围−12～+12、步进1，增益1.0～3.0倍、步进0.1。

单段原始PCM最长5分钟，录音完成后可换音效回放。存储14648438个16位样本，占29296876字节，末尾按DDR块补零；断电或全局复位失效。回放中修改音效、半音会在当前位置经过短淡出／淡入继续；暂停后短按播放键从原位置继续，长按播放键再松开从头重播。

|控件|操作|
|---|---|
|外接按键1短按|切换实时／录放；回到实时先静音，已提交录音保留|
|外接按键1长按2秒后松开|全局复位，录音失效，所有参数恢复默认|
|外接按键2|原声→变调→和声→原声|
|外接按键3|录放模式开始／结束录音；回放／暂停时先结束会话，再按才重录|
|外接按键4短按|播放／暂停／继续|
|外接按键4长按后松开|从头重播；约1秒，内部判定0.8秒|
|旋钮1转动|调整增益，端点停止、不回绕|
|旋钮1短按|实时模式切麦克风／静音，测试音中按下退出到静音|
|旋钮2转动|变调调普通半音；和声调当前声部半音|
|旋钮2短按|和声中选择声部1／2；普通音效中半音归零|
|旋钮2长按2秒后松开|当前半音归零；和声中只归零选定声部|

隐藏测试音手势：仅实时模式，双旋钮连续同时按住2秒，全部松开后进入；短组合会取消，不附带两个单按。LCD底部为实时／录放两页固定四行提示，不轮播、不列测试音维护手势。灯环颜色为原声青色、变调紫色、和声黄色；录音／保存红色，存储等待／测试音蓝色，故障状态优先。


灯环校准余量固定为 **−1500**，自动门限为 `clamp(2×开机校准基线−1500, 64, 65535)`，实际门限由启动校准决定；开机最初约两秒请尽量保持安静。运行时不提供余量调参入口，不占用旋钮1长按，LCD保留正常播放时间和固定操作提示，不显示调试均值。重新上电或全局复位后余量仍为−1500，无需每次调节。这个参数写在FPGA设计中，不是保存用户录音或旋钮运行值。

灯环低亮度区采用较低的SK9822全局亮度：level小于64时为4～7／31，level达到64后为原8／31；RGB仍为level除以2。低幅度时采用较低的全局亮度，较大幅度时使用8／31全局亮度。采样窗口、声音门限硬下限64、颜色和衰减节奏由灯环逻辑控制。音频路径、音效、录放及增益算法不受灯环调整影响。


接线使用121根固定管脚，LCD-Connector与J17保持配套接线要求。外接旋钮与按键针脚图见[引脚约束图](docs/hardware/外接旋钮与按键的引脚约束.png)。重建与验证范围见[使用与上板验证](docs/使用与上板验证.md)和[软件验证](docs/软件验证.md)。
