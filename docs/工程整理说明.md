# 高云FPGA实时变调与和声系统工程文件说明

完整工程含设计源码、IP、约束、ROM、测试台与测试输入、烧录位流及设计说明。

组长提交包内的两份上轮整理清单、一份构建检查点、两份旧审计输入清单、一张历史面板照片和两张调参分支预览已清理。最终构建、时序和管脚报告，以及字体和厂商许可仍可查阅。

正式位流供手动选择，其文件名可独立设置。交付位流、配套版本说明、静态报告和预览图采用中文功能名。历史报告保留生成时的名称记录。

主工程 audio_lcd_record_b.gprj 和 IP 工程 ipgen.gprj 的文件名由 Tcl 构建入口指定。RTL、IP、约束、ROM、头文件和测试数据按工程清单、include、readmem 或测试台中的相对路径读取，故沿用原名。构建时可将解压出的工程目录复制到 D:/FPGA/AudioHarmony 后运行 build.tcl。
