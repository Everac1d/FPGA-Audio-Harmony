# 和声与灯环调参交互、显示

此记录描述保留模块的设计，包括可选调试分支；当前33号正式配置关闭调参入口，固定余量为−1500，以根目录README.md为准。以下+24等描述对应调试分支默认值，不是正式版运行参数。

正常音效循环为原声、变调、和声三项。和声具有两个独立半音参数，默认均为+00，普通变调参数仍独立保存、默认0。旋钮2在和声中短按切换当前声部、旋转调整当前声部、长按2秒松手归零当前声部；普通音效中短按或长按均将普通半音归零。选择声部只改变编辑目标，不应触发音频淡出。

正式版关闭`RING_TUNE_ENABLE`，旋钮1保持增益调节及实时麦克风／静音。调试版打开该参数：长按旋钮1两秒后松手进入／退出灯环调节，长按不会附带短按静音；灯环调节中转旋钮1只调整校准余量，增益目标保持。慢转每格1；连续同向快转间隔小于120ms时，前两格仍为1，第三格起为16；停顿或换向恢复细调。范围−4096～+4095，默认+24，端点饱和、不回绕。

调试版短按旋钮1仍可实时静音／恢复麦克风，旋钮2仍为音效／声部控制。切实时／录放会退出调参、保留余量；若切源时旋钮1仍按着，该次按压会取消直至完全松开，旧松手不会重进调参或意外静音，下一次完整按压恢复正常。全局复位恢复+24。实时双旋钮连续同时按2秒、全部松开后的测试音手势优先，吞掉两个单按及长按，不会同时切调参或半音归零；进入测试音时退出灯环调参。录放下组合键不能进入测试音。

LCD主区保持24像素字形，底部保持4行16像素且只按实时／录放选两组固定提示。没有定时轮播；操作提示不列测试音维护手势。所有时间为八个ASCII半格的`MM:SS.cc`，完整五分钟为`05:00.00`。

正式版保留录音、总长和播放时间。调试版以第四主信息行显示“灯环 余量+0024 门限00152 均值00184”；该行在退出调参后仍显示最近数据，进入调参时顶部标题为“灯环调节”。录音、总长和进度条保持；调试版播放时间由进度条辅助观察。存储故障时错误码行优先。显示的均值和门限是PCM数字幅度，不是声压分贝。

新快照状态共91bit，包含两个声部、编辑目标和全部校准显示值；五分钟的32bit样本数先限幅后用40bit顺序除法，四个商共164个50MHz时钟，时间为16bit百分秒。快照完成后等待下一帧一次发布，不将显示计算反向施加到音频。

新生产字体独立使用256槽、134字形的24px及16px ROM，保留原有128槽字体数据，以及原文字头和旧LCD模块的非注释内容。原字形编号沿用，新增“灯环／余量／门限／均值”等字形用完整8bit索引，不截掉编号高位。来源仍为本机OFL Noto Sans SC，来源哈希、边界及资源哈希见`fonts/HARMONY_FONT_MANIFEST.json`，许可见同目录OFL.txt。

LCD预览位于`lcd_previews/`，由原版本RTL光栅输出转换得到，不是实屏照片。整理包保留相关测试台与通用仿真入口`sim/run.py`；专用预览转换脚本和历史运行输出已清理。
