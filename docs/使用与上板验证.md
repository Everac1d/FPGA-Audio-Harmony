# 33号使用与上板验证

完整解压后打开根目录audio_lcd_record_b.gprj；器件GW5AST-138B，顶层audio_record_ddr_top。本次直接下载ready_to_program/33_harmony_5min_margin_m1500_B.fs，UserCode为0x00033109；FS哈希见同目录BUILD_INFO.json和SHA256SUMS.txt。

保持目前已经工作的LCD、扬声器、麦克风阵列和外接按键／旋钮接线。开机约两秒保持安静以校准噪声基线；默认实时静音，短按旋钮1打开麦克风。余量固定−1500，重启后仍是该值；实际门限随每次启动校准结果变化，不保证每次都是610。灯环起亮约为原亮度一半，较大声音时保持原亮度。

操作详见根目录README_先读.md，LCD底部继续按实时／录放显示两页固定提示。和声只有一个模式，两个独立声部默认0／0；旋钮2短按选声部，旋转调±12半音，长按2秒松手归零当前声部。旋钮1调增益1.0～3.0倍，步进0.1；日常按下切麦克风／静音。正式版没有灯环调参入口。

建议复测小声到大声的亮度层次、安静时不常亮、青／紫／黄色切换，以及录放暂停继续和回放中改音效／半音。五分钟长录音重点检查跨30秒、3分钟、05:00.00满段自动结束和末尾完整播放。录音在DDR中，断电或全局复位失效。

重建：使用根目录build.ps1 -Action build -Python 'D:\PYTHON\python.exe'。需要先准备仿真报告，已有报告只在源码哈希一致时可复用；硬件资源和时序检查由finalize严格执行，不可只看编译进度100%。独立专项入口sim/run_harmony_tuned_engine.py和sim/run_ring_softlow.py；通用sim/run.py可选具体测试名称。工具路径按安装情况传入。

串口115200／8N1，R6状态117字节与D3诊断164字节成对发送。L／P是32位8位十六进制样本数，H为0.1倍，N／Q为5位有符号半音，C表示当前编辑声部0／1。analyze_status.py和read_status.ps1已加入33109解析；只有用户主动运行read_status.ps1才会打开设备。本次不进行硬件下载或串口操作。
