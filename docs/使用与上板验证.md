# 33号工程使用与重建

本整理包的器件为GW5AST-138B / GW5AST-LV138PG484AC1/I0，顶层为`audio_record_ddr_top`，UserCode为`0x00033109`。建议完整解压到全英文短路径，例如`D:/FPGA/AudioHarmony`。根目录的`audio_lcd_record_b.gprj`用于浏览工程；重新构建使用保留的`build.tcl`，以完整应用原版顶层、版本号、压缩、布局布线和配置脚复用选项。

## 使用现成烧录文件

正式文件为`ready_to_program/高云FPGA实时变调与和声系统_正式烧录位流.fs`，SHA256为：

```text
8A577D06C4037933807A0D05FB2EB6CA57CD9FA2A9F360C88DE4E5A05C9F2749
```

该文件与用户提供的压缩包逐字节相同。器件及配置参数见同目录`烧录版本信息.json`；完整交付文件校验值见根目录`SHA256SUMS.txt`。使用与B版器件匹配的Gowin Programmer手动选择该文件；操作说明见根目录`README.md`。本次整理没有连接、下载或复位开发板。

## 重新构建

原项目使用Gowin V1.9.12.04 x64。在Windows命令提示符中进入工程根目录，调用本机安装的Gowin Shell，例如：

```bat
cd /d D:\FPGA\CloudHarmony
"D:\Gowin\Gowin_V1.9.12.04_x64\IDE\bin\gw_sh.exe" build.tcl
```

将工具路径替换为实际安装位置。构建输入已齐备，不需要先运行Python分析、字体生成或PowerShell脚本。`build.tcl`保留`use_sspi_as_gpio`和`use_cpu_as_gpio`选项，两者关系到外接控件管脚复用。工程只启用`constraints/audio_record_ddr.cst`与`constraints/audio_speaker.sdc`；其余约束保留作设计参考。

重新构建生成的文件位于`impl/pnr/`。应复核新的资源、时序和管脚报告，确认121个物理管脚固定且Setup/Hold均无全局违例。`docs/reports/`为原交付版本报告，不能替代本次重新构建的结果。构建不会自动更新`ready_to_program/`中的原版正式文件。

## IP与仿真

`ip/`保留已生成的B版DDR3与PLL代码和参数。日常构建直接使用这些文件。`ip/generate_ip.tcl`及`ip/ipgen.gprj`仅供需要重新生成IP时使用；执行会覆盖生成文件，应先另存工程副本。

仿真保留最小入口`sim/run.py`、全部测试台及`sim/fixtures/`数据。在已安装Python 3和Windows Icarus Verilog的环境中，从工程根目录运行，例如：

```bat
python sim/run.py --icarus "D:\tools\iverilog\bin" tb_ring_softlow tb_harmony_tuned_engine
```

不指定测试名时运行全部测试台。入口会创建`sim/results/`存放新输出；此目录不包含在交付包中。专用频谱后处理、历史依赖复用与自动发布审计脚本已清理，通用入口不等同于旧版全部专项数值审计。

## 上板复核与串口

保持已工作的LCD、扬声器、麦克风阵列和按键／旋钮接线。开机约两秒保持安静以校准噪声基线；默认实时静音，短按旋钮1打开麦克风。灯环余量固定为−1500，门限由本次启动基线计算，并非固定610。

复测可覆盖小声到大声的亮度层次、安静时不常亮、三种音效颜色，以及暂停继续和回放中改音效。五分钟录音边界关注跨30秒、3分钟、05:00.00自动结束和末尾播放；DDR录音在断电或全局复位后失效。

串口使用115200／8N1，R6状态117字节与D3诊断164字节成对发送；L／P为32位样本数的8位十六进制表示，H以0.1倍为单位，N／Q为5位有符号半音，C为当前编辑声部0／1。整理包不附带串口控制脚本，可自行使用串口终端查看。
